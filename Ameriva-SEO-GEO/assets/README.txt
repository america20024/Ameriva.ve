AMERIVA - LOGOS E ICONOS TRANSPARENTES

Todos los favicon y PNG principales fueron exportados con fondo transparente.

Archivos para subir a la raíz:
- /favicon.ico
- /apple-touch-icon.png
- /logo.png
- /manifest.json

Archivos para subir en /icons/:
- /icons/icon-192.png
- /icons/icon-512.png

Open Graph:
- og-ameriva-transparent.png tiene fondo transparente.
- og-ameriva.jpg tiene fondo blanco y es más recomendable para redes sociales, porque muchas plataformas no manejan bien transparencias.

Código recomendado:
<link rel="icon" href="/favicon.ico">
<link rel="apple-touch-icon" href="/apple-touch-icon.png">
<link rel="manifest" href="/manifest.json">
<meta property="og:image" content="https://ameriva.com.ve/og-ameriva.jpg">
<meta name="twitter:image" content="https://ameriva.com.ve/og-ameriva.jpg">
